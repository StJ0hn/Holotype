# Holotype — Contexto do Projeto

## Natureza do Projeto
Projeto de aprendizado deliberado (learning environment) usando stack TypeScript fullstack moderna.

## Stack Tecnológica
- Backend: Nest.js
- Frontend: React + Vite
- ORM: Prisma
- Banco: PostgreSQL
- Autenticação: JWT
- Containerização: Docker

## Estrutura do Repositório
```
holotype/
├── backend/      # API Nest.js
├── frontend/    # React + Vite
├── shared/      # Tipos TypeScript compartilhados
└── sandbox/
```
